# АРМ «Спортивный организатор»

Курсовой проект, тема 7. Настольное приложение для организатора спортивных соревнований и тренеров команд.

Программа помогает вести турниры в одном месте: от регистрации команд и рассмотрения заявок до построения сетки, расписания матчей, фиксации результатов и подготовки отчётов.

## Технологии

- Python 3
- PyQt6 — графический интерфейс
- SQLite — локальное хранение данных
- openpyxl — экспорт отчётов в Excel

## Запуск

Из корня репозитория:

```bash
python -m pip install -r sport_arm/requirements.txt
python sport_arm/main.py
```

Либо из каталога приложения:

```bash
cd sport_arm
python -m pip install -r requirements.txt
python main.py
```

## Учётные записи для демонстрации

| Роль | Логин | Пароль |
|---|---|---|
| Организатор | `admin` | `admin` |
| Демо-тренер | `coach` | `coach` |

Демо-тренер доступен после загрузки демонстрационных данных. Для реальной эксплуатации стандартные демонстрационные пароли необходимо заменить.

## Возможности

### Организатор
- создавать, редактировать и удалять турниры;
- принимать, отклонять и возвращать на рассмотрение заявки команд;
- просматривать команды и составы игроков;
- формировать олимпийские сетки и круговые турниры;
- назначать матчи вручную или строить расписание автоматически;
- вносить результаты и отслеживать ход соревнований;
- просматривать турнирные таблицы и рейтинг Эло;
- выгружать таблицы, расписание, заявки, составы и рейтинги в XLSX или CSV.

### Тренер / капитан
- зарегистрировать команду и управлять её данными;
- добавлять, изменять и удалять игроков состава;
- подавать и отзывать заявки на турниры;
- просматривать сетку, расписание и результаты;
- отслеживать статистику и историю выступлений команды.

## Структура репозитория

```text
sport_arm/
├── main.py             # точка запуска PyQt6-приложения
├── qt_main.py          # интерфейс и рабочие экраны
├── database.py         # бизнес-логика и SQLite
├── main_tkinter.py     # предыдущий прототип интерфейса
├── requirements.txt    # зависимости
└── tests/
    └── test_logic.py   # тесты бизнес-логики
```

## Тестирование

Из корня репозитория:

```bash
python -m unittest discover -s sport_arm/tests -v
```

Из каталога `sport_arm`:

```bash
python -m unittest discover -s tests -v
```

База данных приложения находится в `sport_arm/sport_arm.db`. Не удаляйте этот файл, если в нём находятся нужные данные. Для чистой демонстрации можно предварительно сохранить резервную копию базы.
