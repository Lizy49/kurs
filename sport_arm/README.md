# АРМ «Спортивный организатор»

Настольное приложение для организатора соревнований и тренеров команд. Интерфейс реализован на **Python + PyQt6**, данные хранятся в **SQLite**.

## Запуск

Из каталога `sport_arm`:

```bash
python -m pip install -r requirements.txt
python main.py
```

Из корня репозитория:

```bash
python -m pip install -r sport_arm/requirements.txt
python sport_arm/main.py
```

## Роли и демонстрационный вход

| Роль | Логин | Пароль |
|---|---|---|
| Организатор | `admin` | `admin` |
| Демо-тренер | `coach` | `coach` |

Демо-тренер доступен после загрузки демонстрационных данных.

## Команды Федерации волейбола г. Магадан

В разделе **«Команды»** нажмите **«Загрузить команды с сайта»**. Приложение добавит 14 уникальных команд из опубликованных таблиц:

- 11 команд ЛВЛ сезона 2026–2027;
- 11 записей таблицы ЛВЛ сезона 2025–2026;
- 3 команды, встречающиеся только в таблице прошлого сезона: «Бей-Беги», «Больные Колени» и «Искра».

Статистика хранится раздельно по сезонам: место, очки, сыгранные матчи, победы, поражения, очки в партиях и коэффициенты. Повторный импорт не создаёт дубликаты команд и не перезаписывает вручную указанные город и капитана.

Источники снимка данных (зафиксирован 14.11.2026):
- [Федерация волейбола г. Магадан — главная страница и таблица ЛВЛ 2026–2027](https://volleyball-mgdn.ru/)
- [ЛВЛ 2025–2026](https://volleyball-mgdn.ru/tournament/лвл-2025-2026/)

Это локальный снимок опубликованных таблиц, а не автоматическая синхронизация сайта в реальном времени. Составы игроков не создаются автоматически: общая страница игроков не содержит надёжной привязки всех спортсменов к командам. Состав заполняется тренером или организатором после проверки.

## Возможности организатора

- создание, изменение и удаление турниров;
- рассмотрение заявок на участие;
- просмотр команд и составов игроков;
- построение сеток для олимпийской и круговой систем;
- ручное и автоматическое расписание матчей;
- ввод и очистка результатов;
- турнирные таблицы, рейтинг Эло и история команд;
- экспорт в Excel (.xlsx) и CSV (.csv).

## Возможности тренера / капитана

- регистрация команды и изменение её данных;
- управление составом игроков;
- подача и отзыв заявок на турниры;
- просмотр расписания, сетки и результатов;
- статистика и история матчей.

## Сброс локальной базы

Перед сбросом закройте приложение. Из каталога `sport_arm` выполните:

```bash
python reset_database.py
```

Скрипт запросит подтверждение, создаст копию `sport_arm.db` с датой и временем в имени и только после этого создаст пустую базу. Учётная запись организатора будет восстановлена: `admin / admin`. После запуска программы откройте раздел «Команды» и нажмите «Загрузить команды с сайта».

Резервную копию можно использовать для восстановления старых данных. Не удаляйте её, пока не убедитесь, что новая база работает как нужно.

## Файлы

- `main.py` — запуск PyQt6-версии.
- `qt_main.py` — интерфейс.
- `database.py` — бизнес-логика, SQLite и сезонная статистика.
- `website_import.py` — проверенный снимок команд и таблиц Федерации.
- `reset_database.py` — безопасный сброс базы с резервной копией.
- `main_tkinter.py` — предыдущий прототип интерфейса.
- `sport_arm.db` — локальная база данных.
- `tests/test_logic.py` — автоматические тесты.
