# АРМ «Спортивный организатор»

Настольное приложение для организатора соревнований и тренеров команд. Интерфейс реализован на **Python + PyQt6**, данные хранятся в **SQLite**.

## Запуск

Из каталога `sport_arm`:

```bash
python -m pip install -r requirements.txt
python main.py
```

Если запускаете из корня репозитория:

```bash
python -m pip install -r sport_arm/requirements.txt
python sport_arm/main.py
```

## Роли и демонстрационный вход

| Роль | Логин | Пароль |
|---|---|---|
| Организатор | `admin` | `admin` |
| Демо-тренер | `coach` | `coach` |

Демо-тренер доступен после загрузки демонстрационных данных: войдите как организатор → «Турниры» → «Загрузить демо-данные».

## Интерфейс

- отдельный экран входа и регистрации тренера;
- боковая навигация по разделам в зависимости от роли;
- главная панель с ключевыми показателями и быстрыми действиями;
- прокручиваемое меню, чтобы навигация оставалась доступной на небольших экранах;
- единый стиль таблиц, форм, карточек и кнопок;
- обновление данных клавишей **F5**.

## Возможности организатора

- создание, изменение и удаление турниров;
- рассмотрение заявок на участие;
- просмотр команд и составов игроков;
- построение сеток для олимпийской и круговой систем;
- ручное и автоматическое расписание матчей;
- ввод и очистка результатов;
- турнирные таблицы, рейтинг Эло и история команд;
- экспорт в Excel (.xlsx) и CSV (.csv).

## Возможности тренера / капитана

- регистрация команды и изменение её данных;
- управление составом игроков;
- подача и отзыв заявок на турниры;
- просмотр расписания, сетки и результатов;
- статистика и история матчей своей команды.

## Файлы

- `main.py` — точка запуска активной PyQt6-версии.
- `qt_main.py` — графический интерфейс.
- `database.py` — бизнес-логика, проверки и работа с SQLite.
- `main_tkinter.py` — предыдущая версия интерфейса, оставлена как архивный прототип.
- `sport_arm.db` — локальная база данных.
- `tests/test_logic.py` — автоматические тесты бизнес-логики.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Важно

Бизнес-логика и структура базы вынесены в `database.py` и не зависят от PyQt6. При первом запуске создаётся структура БД и учётная запись организатора. Перед удалением или заменой `sport_arm.db` обязательно сохраните резервную копию, если в базе есть нужные данные.
