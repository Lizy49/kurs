# АРМ «Спортивный организатор»

Настольное приложение для организатора соревнований и тренеров команд. Интерфейс: **Python + PyQt6**, база: **SQLite**.

## Запуск

Из каталога `sport_arm`:

```bash
python -m pip install -r requirements.txt
python main.py
```

Из корня репозитория:

```bash
python -m pip install -r sport_arm/requirements.txt
python sport_arm/main.py
```

## Импорт 11 команд и составов ЛВЛ 2026–2027

Войдите как организатор → раздел **«Команды»** → **«Импортировать составы и аккаунты ЛВЛ 26–27»**.

Будут загружены:
- 11 команд текущего сезона;
- 133 строки официальных составов за 2026–2027;
- сезонная статистика каждого игрока: приём, блок, эйс, защита, ошибки;
- капитан каждой команды из её страницы Федерации;
- 11 локальных учётных записей роли «тренер / капитан».

Игроки и статистика прошлого сезона не добавляются в составы. Сезон 2025–2026 сохраняется только в архивной таблице команд. Позиции игроков и даты рождения не заполняются, если их нет в источнике.

## Отдельный список игроков

В разделе «Команды» две вкладки:
- **ЛВЛ 2026–2027** — официальный состав и текущая статистика с сайта;
- **Локальные карточки** — внутренние записи `players`, где можно вести подтверждённую позицию и год рождения.

Это разделение нужно, чтобы не выдумывать для игроков недостающие сведения и не смешивать официальный список со внутренними анкетами.

## Возможности приложения

**Организатор:** турниры, заявки, команды, сетки, расписание, результаты, турнирные таблицы, рейтинг Эло, экспорт XLSX/CSV.

**Тренер / капитан:** команда, локальный состав, заявки, расписание, сетка, статистика и история матчей.

## Сброс SQLite

Закройте приложение и запустите из каталога `sport_arm`:

```bash
python reset_database.py
```

Введите `RESET`. Скрипт создаст резервную копию `sport_arm.db`, затем создаст новую пустую базу. После входа под `admin / admin` выполните импорт составов ЛВЛ 26–27.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Структура

- `main.py` — запуск приложения.
- `qt_main.py` — интерфейс.
- `database.py` — SQLite и бизнес-логика.
- `website_import.py` — текущие составы, статистика и создание локальных аккаунтов капитанов.
- `reset_database.py` — безопасный сброс базы с резервной копией.
- `tests/test_logic.py` — автоматические тесты.
