# АРМ «Спортивный организатор» — тема 7

Приложение для организатора соревнований и тренеров команд. Интерфейс реализован на **Python + PyQt6**, данные хранятся в **SQLite**.

## Запуск

Из каталога проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

На Linux при необходимости установите системные библиотеки Qt, если их не подтянет ваша сборка Python.

База данных `sport_arm.db` находится рядом с программой. При первом запуске создаётся база и учётная запись организатора.

## Вход

| Роль | Логин / пароль |
|---|---|
| Организатор | `admin / admin` |
| Тренер | регистрация на экране входа |
| Демо-тренер | `coach / coach` после загрузки демо-данных |

Чтобы быстро показать работу: войдите как `admin` → вкладка «Турниры» → «Загрузить демо-данные».

## Возможности

### Организатор
- Создание, изменение и удаление турниров.
- Олимпийская и круговая системы проведения.
- Рассмотрение заявок команд: одобрение, отклонение, возврат на рассмотрение и одобрение всех ожидающих заявок.
- Просмотр команд и составов.
- Генерация турнирной сетки с посевом по рейтингу и автоматическими проходами.
- Ручное и автоматическое расписание без накладок команд и площадок.
- Ввод и очистка результатов матчей.
- Турнирная таблица, рейтинг Эло и история команд.
- Экспорт таблиц, расписания, заявок, составов и рейтинга в XLSX или CSV.

### Тренер / капитан
- Регистрация команды и редактирование её данных.
- Добавление, изменение и удаление игроков состава.
- Подача и отзыв заявок на турниры.
- Просмотр расписания и сетки с выделением матчей своей команды.
- Статистика выступлений и история матчей.

## Структура

- `main.py` — основной запуск PyQt6-версии.
- `qt_main.py` — интерфейс PyQt6.
- `database.py` — бизнес-логика, проверки и работа с SQLite. Не зависит от GUI.
- `main_tkinter.py` — сохранённая исходная версия интерфейса Tkinter.
- `tests/test_logic.py` — тесты бизнес-логики.

Запуск тестов:

```bash
python -m unittest discover -s tests
```

## Важно

Логика и структура базы данных в `database.py` не переписывались. Новая версия интерфейса обращается к тем же методам базы данных и использует тот же файл `sport_arm.db`.
