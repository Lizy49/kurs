# АРМ «Спортивный организатор» (курсовая работа, тема 7)

Приложение на Python + Tkinter + SQLite. Организатор ведёт турниры, заявки команд,
сетки, расписание и результаты; тренер управляет составом, подаёт заявки и смотрит
статистику своей команды.

## Запуск
    pip install openpyxl        # нужен только для экспорта в .xlsx
    python main.py

Tkinter входит в стандартную поставку Python (на Linux: `sudo apt install python3-tk`).
База `sport_arm.db` создаётся рядом с программой при первом запуске.

## Вход
| Роль        | Логин / пароль |
|-------------|----------------|
| Организатор | admin / admin  |
| Тренер      | регистрация на экране входа, либо coach / coach после загрузки демо-данных |

Чтобы быстро всё показать: войдите как admin → вкладка «Турниры» → «Загрузить демо-данные».

## Возможности
**Организатор:** создание/правка/удаление турниров (олимпийская и круговая системы) ·
рассмотрение заявок · автоматическая сетка с посевом по рейтингу и автопроходами ·
расписание вручную и автоматическое (без накладок команд и площадок) · ввод, правка
и очистка результатов · турнирная таблица · автоматический рейтинг Эло ·
экспорт в Excel и CSV (таблица, расписание, заявки, составы, рейтинг).

**Тренер:** редактирование команды и состава (проверка номеров, годов, лимитов) ·
заявки на турниры (минимум 5 игроков) · расписание и сетка с подсветкой своей команды ·
личная статистика и история матчей.

## Структура
- `database.py` — вся логика и работа с БД (без tkinter);
- `main.py` — интерфейс;
- `tests/test_logic.py` — автотесты логики: `python -m unittest discover -s tests`.
