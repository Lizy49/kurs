# АРМ «Спортивный организатор»

Настольная программа для ведения волейбольных команд и проведения соревнований. Интерфейс — **Python + PyQt6**, данные хранятся локально в **SQLite**.

## Запуск

Из корня репозитория:

```bash
python -m pip install -r sport_arm/requirements.txt
python sport_arm/main.py
```

Или из каталога `sport_arm`:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Первый запуск

Программа не содержит готовых пользователей, паролей, команд, игроков или турниров.

При первом открытии появится форма первоначальной настройки. В ней нужно самостоятельно указать ФИО, логин и пароль организатора. Для пароля требуется не менее 8 символов. После сохранения программа сразу откроет рабочее окно.

Дальше вход выполняется по созданным тобой данным. Готовых комбинаций логина и пароля в программе нет.

## Ручное заполнение

После входа открой раздел **«Команды»**.

- **Добавить команду** — укажи название, город и капитана.
- **Изменить команду** — отредактируй сведения выбранной команды.
- **Удалить команду** — удали команду вместе с её составом и заявками.
- **Добавить игрока** — заполни ФИО, номер, амплуа и год рождения.
- **Изменить / Удалить** — веди карточки игроков вручную.

Позицию можно оставить как «Не указано» и заполнить позднее. Программа не подставляет вымышленные данные и не загружает составы из сторонних источников.

## Возможности

**Организатор:** создание и редактирование команд, составов, турниров и заявок; формирование сетки; расписание матчей; ввод результатов; турнирная таблица; рейтинг команд; экспорт в XLSX и CSV.

**Волейбольные матчи:** результат вводится отдельно по каждой партии. Первые четыре партии играются до 25 очков, пятая — до 15; для победы требуется преимущество минимум в 2 очка. Матч заканчивается после трёх выигранных партий. В таблице и сетке отображаются общий результат и счёт каждой партии.

**Протоколы:** в разделе «Матчи и расписание» можно экспортировать протокол выбранного сыгранного матча. В разделе «Экспорт» доступна выгрузка всех сыгранных матчей за выбранную дату, по всему приложению или в рамках выбранного турнира.

**Тренер / капитан:** регистрация своей команды, управление составом, подача заявок на открытые соревнования, просмотр сетки, расписания, турнирной таблицы и статистики.

## Сброс базы данных

Если в локальной базе остались прежние тестовые записи, закрой программу и из каталога `sport_arm` выполни:

```bash
python reset_database.py
```

Подтверди сброс словом `RESET`. Скрипт сохранит старую базу в файл резервной копии и создаст пустую. При следующем запуске ты заново создашь логин и пароль организатора.

## Проверка

Из каталога `sport_arm`:

```bash
python -m unittest discover -s tests -v
```

## Структура

- `main.py` — запуск приложения.
- `qt_main.py` — интерфейс PyQt6.
- `database.py` — SQLite и бизнес-логика.
- `reset_database.py` — сброс базы с резервной копией.
- `tests/test_logic.py` — автоматические тесты.
